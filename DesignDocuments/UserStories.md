# User Stories

## MVP User Stories

### User Authentication and Account Management

#### Register an Account *

As a new user, I want to create an account so that I can generate, save, and manage my recipes.

#### Sign In *

As a registered user, I want to sign in so that I can access my personal recipe library.

#### Sign Out *

As a signed-in user, I want to sign out so that other people using the same device cannot access my account.

### AI Recipe Generation

#### Start a Recipe Conversation *

As a registered user, I want to describe the type of recipe I want in a chat so that RecipeForge can generate personalized recipe ideas for me.

#### Clarify a Recipe Request *

As a registered user, I want to add details after my first request so that I can refine the recipe without starting over.

#### Receive Multiple Recipe Ideas *

As a registered user, I want to receive several recipe ideas in the conversation so that I can choose the option I like best.

#### Generate a Structured Recipe *

As a registered user, I want RecipeForge to generate a recipe with a title, ingredients, amounts, instructions, serving information, difficulty, and cooking time so that the recipe is organized and easy to follow.

#### Review a Generated Recipe *

As a registered user, I want to review a generated recipe before saving it so that I can decide whether it meets my needs.

#### Edit a Generated Recipe *

As a registered user, I want to edit a generated recipe before saving it so that I can correct or personalize its ingredients and instructions.

#### Handle a Recipe Generation Error *

As a registered user, I want to receive a clear message when a recipe cannot be generated so that I know I should revise my request or try again.

### Manual Recipe Creation

#### Add a Recipe Manually *

As a registered user, I want to create a recipe without using AI so that I can save recipes I already know.

#### Add Structured Ingredients *

As a registered user, I want to enter each ingredient with its amount and unit so that my saved recipe has an organized ingredient list.

#### Add Recipe Instructions *

As a registered user, I want to add instructions as individual steps so that the recipe is easy to follow.

### Recipe Library and Viewing

#### Save a Recipe *

As a registered user, I want to save a generated or manually created recipe so that I can access it again later.

#### Open My Recipes After Sign-In *

As a registered user, I want My Recipes to open after I sign in so that I can immediately access my saved recipes.

#### Browse Saved Recipes *

As a registered user, I want to browse the recipes in my personal library so that I can see what I have saved.

#### Search Saved Recipes *

As a registered user, I want to search my saved recipes by name so that I can quickly find a particular recipe.

#### Sort Saved Recipes *

As a registered user, I want to sort my saved recipes so that I can control how they are displayed.

#### View a Saved Recipe *

As a registered user, I want to view a saved recipe's ingredients, amounts, serving information, difficulty, cooking time, and instructions so that I can prepare the recipe.

#### View Only My Recipes *

As a registered user, I want my personal recipe library to contain only recipes associated with my account so that my recipes remain separate from those belonging to other users.

### Recipe Management

#### Edit a Saved Recipe *

As a registered user, I want to edit a recipe in my library so that I can correct it or adapt it to my needs.

#### Delete a Saved Recipe *

As a registered user, I want to delete a recipe that I no longer need so that my recipe library remains useful and organized.

#### Confirm Recipe Deletion *

As a registered user, I want to confirm a deletion so that I do not remove a recipe accidentally.

## Non-MVP User Stories

### Recipe Preferences

#### Save Food Restrictions

As a registered user, I want to save allergies and ingredients to avoid so that RecipeForge can apply them to future recipe requests.

#### Save Dietary Preferences

As a registered user, I want to save dietary preferences so that I do not have to enter them every time I generate a recipe.

#### Save Recipe Defaults

As a registered user, I want to save my preferred difficulty, serving count, and maximum cooking time so that new recipe conversations start with useful defaults.

#### Override a Preference

As a registered user, I want to override a saved preference during a conversation so that one recipe can be different from my usual choices.

### Recipe Discovery and Organization

#### Filter Saved Recipes

As a registered user, I want to filter recipes by attributes such as meal type or dietary preference so that I can find recipes that match my current needs.

#### Organize Recipes into Collections

As a registered user, I want to organize recipes into collections so that I can group related recipes together.

#### Mark Recipes as Favorites

As a registered user, I want to mark recipes as favorites so that I can easily access the recipes I use most often.

### Recipe Features

#### Scale Recipe Servings

As a registered user, I want to change the number of servings so that ingredient amounts can be adjusted for the number of people I am serving.

#### Choose Measurement Preferences

As a registered user, I want to choose between US customary and metric measurements so that recipes use units that are familiar to me.

#### Generate a Variation of a Saved Recipe

As a registered user, I want to generate a variation of an existing recipe so that I can try a different version without starting over.

#### Add a Recipe Photo

As a registered user, I want to add a photo to a recipe so that I can recognize it more easily in my library.

### Meal Planning

#### Create a Meal Plan

As a registered user, I want to place saved recipes into a meal plan so that I can plan meals in advance.

#### Create a Shopping List

As a registered user, I want to create a shopping list from selected recipes so that I know which ingredients to purchase.

### Sharing

#### Share a Recipe

As a registered user, I want to share a recipe with another person so that they can view or prepare it.

#### Export a Recipe

As a registered user, I want to export or print a recipe so that I can use it outside RecipeForge.

### Account Management

#### Edit User Profile

As a registered user, I want to edit my profile so that my account information remains current.

#### Reset Password

As a registered user, I want to reset my password if I cannot sign in so that I can regain access to my recipe library.

* Denotes an MVP user story.
